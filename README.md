# Enterprise Customer Integration and Operations Platform

An independent portfolio project demonstrating practical software engineering, backend development, database engineering, API integration, and software architecture using the .NET ecosystem.

## Project Overview

The goal is to build an enterprise-oriented platform for managing customer and organisation data, integrating external APIs, validating and transforming data, and processing reliable data import workflows.

The application will evolve incrementally, following sound engineering practices and documenting important technical decisions.

## Technology Stack

- C#
- .NET / ASP.NET Core
- SQL Server
- Entity Framework Core
- REST APIs
- Docker
- GitHub Actions / Azure DevOps
- Microsoft Azure

Technologies will be introduced when they are justified by project requirements.

## Key Features

- Customer and organisation management
- RESTful API development
- External API integration
- Data validation and transformation
- Data import workflows
- Database design and optimisation
- Authentication and authorisation
- Audit logging and observability
- Background processing and retry handling
- Automated testing
- Containerisation and deployment
